# Wealth

Wealth is a Personal Financial Management Platform designed to help users manage their income, investments, goals, cash flow, and financial decisions.

## Vision

Build a modern financial platform that enables users to:

- Track their net worth
- Manage investments
- Plan future goals
- Analyze cash flow
- Make better financial decisions

## Technology Stack

- ASP.NET Core (.NET)
- PostgreSQL
- React
- Docker
